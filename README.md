# Age Calculator

An interactive and responsive Age Calculator web application built with React, Vite, and Tailwind CSS.

This project was built as a solution to the **[roadmap.sh Age Calculator Challenge](https://roadmap.sh/projects/age-calculator)**.

---

## 🚀 Features

- **Accurate Age Calculation**: Calculates exact age in years, months, and days using [Luxon](https://moment.github.io/luxon/).
- **Interactive Date Picker**: Integrated date picker with validation to prevent future dates.
- **Modern & Responsive Design**: Clean and accessible UI styled with Tailwind CSS.
- **Comprehensive Unit Testing**: Tested with Vitest and React Testing Library.
- **Code Quality**: Linting and formatting set up with ESLint and Prettier.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler & Tooling**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Date Handling**: [Luxon](https://moment.github.io/luxon/) & [js-datepicker](https://github.com/qodesmith/datepicker)
- **Testing**: [Vitest](https://vitest.dev/) & [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)
- **Formatting & Linting**: [Prettier](https://prettier.io/) & [ESLint](https://eslint.org/)

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ImranAvenger/age-calculator.git
   cd age-calculator
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

Start the development server:

```bash
npm run dev
```

### Running Tests

Run the test suite with Vitest:

```bash
npm run test
```

Or run tests in watch mode:

```bash
npm run test:watch
```

### Building for Production

Build the project for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

### Code Formatting & Linting

```bash
# Format code
npm run format

# Run ESLint
npm run lint
```
